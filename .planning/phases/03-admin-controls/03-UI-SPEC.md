## Spacing Scale

**Spacing system:** The admin UI uses a **rem-native spacing grid** where the base unit is `0.25rem` (= 4px at 16px root). All valid spacing tokens are multiples of `0.25rem`. The table below maps token names to canonical grid values; any prior spec reference to a non-grid rem value (e.g. `0.7rem`, `0.6rem`, `0.9rem`, `1.2rem`, `0.4rem`) is replaced by the nearest canonical grid value listed here.

| Token | rem Value | Approx px | Usage |
|-------|-----------|-----------|-------|
| gap-xs | 0.25rem | 4px | Icon internal padding, tight spacing, photo grid gap |
| gap-sm | 0.5rem | 8px | Element gap within rows, badge offsets, radio gap |
| gap-md | 0.75rem | 12px | Button padding vertical (replaces `0.7rem`), bulk bar padding vertical (replaces `0.6rem`) |
| gap-std | 1rem | 16px | Row gap between form fields, action button gaps, row padding vertical (replaces `0.9rem`) |
| gap-lg | 1.25rem | 20px | Button horizontal padding (replaces `1.2rem`) |
| pad-card | 1.5rem | 24px | Standard card padding (`padding: '1.5rem'`) |
| gap-xl | 2rem | 32px | Grid column gap, section-level separation |

**Grid gap (photos):** `gap: '4px'` — hard-coded constant used in both portfolio and album photo grids. 4px = `0.25rem`; valid on-grid. Do not change.

**Touch target for inline toggle:** minimum 20×20px clickable area (matches existing ConfirmButton size of `width: '20px', height: '20px'`).

**Spacing Exceptions — sub-4px positioning overrides (explicitly exempt from the rem grid):**

| Value | Location | Justification |
|-------|----------|---------------|
| `1px` | Album row separator gap (`gap: '1px'` in AlbumSortableList) | Matches existing codebase constant; hairline separator, not a layout spacing unit |
| `2px × 4px` | Badge padding (`padding: '2px 4px'`) | SVG icon touch target minimum; sub-grid sizing, not a layout gap |
| `3px` | Badge corner offset (`top: '3px', right: '3px'`) | Matches existing delete-button positioning in DraggablePhotoGrid; pixel-precise overlay anchor |
| `26px` | `DayNightToggleBadge` right offset (`right: '26px'`) | Derived constant: 20px delete-button width + 3px right-offset + 3px buffer = 26px; pixel-precise overlay stack anchor to avoid collision with ConfirmButton, not a layout spacing unit |

> Note: `0.4rem` (~6.4px) is eliminated from all Phase 3 new additions. Use `0.5rem` (8px) instead wherever `0.4rem` was previously referenced (e.g. `marginBottom` in `subLabel`, `labelS`).

## Typography

All sizes are canonical `rem` values. Exactly 4 roles are defined. All prior references to `0.70rem`, `0.56rem`, `0.54rem`, `9px`, `8px`, or `0.52rem` in component specs are consolidated into the nearest canonical role below.

| Role | rem Size | Weight | Letter Spacing | Line Height | Color Token | Applies To |
|------|----------|--------|----------------|-------------|-------------|------------|
| Display heading | `2rem` | 300 | normal | 1.2 | `#E8E4DC` | `pageTitle` — Cormorant Garamond, italic |
| Body / input text | `0.82rem` | 400 | normal | 1.5 | `#E8E4DC` | `inputS`, body copy |
| Button / counter | `0.62rem` | 400 | 0.10em–0.14em | 1 | `#7a7a74` or `#E8E4DC` | `btnPrimary`, `btnOutline`, `btnDelete`, bulk bar buttons, inline toggle button label, `bulkCounter`, `radioLabel` (subsumes `0.70rem`) |
| Sub-label / tag / hint / badge | `0.58rem` | 400 | 0.10em–0.22em | 1 | `#7a7a74` or `#5a5a54` | `subLabel`, `cardTitle`, `labelS`, `tag`, `hint`, album row indicator, badge suffix text, inheritance badge text, reset-override label (subsumes `0.56rem`, `0.54rem`, `0.52rem`, `9px`, `8px`) |

**Display heading:** always `fontFamily: 'var(--font-cormorant,serif)'`, `fontStyle: 'italic'`, `fontWeight: 300`.

**Badge icon sizing:** lucide-react `<Sun size={10} />` / `<Moon size={10} />` and `<Sun size={9} />` / `<Moon size={9} />` — icon `size` prop controls SVG dimensions directly, not via CSS `fontSize`. These are icon props, not font-size declarations.

**Specific size rules for Phase 3 new elements:**
- Inline toggle button label inside photo card: `0.62rem`, `letterSpacing: '0.14em'`
- Badge icon (lucide-react `<Sun>` / `<Moon>`): `size={10}` prop
- Bulk action bar button labels: `0.62rem`, `letterSpacing: '0.14em'`
- "(N sélectionné(s))" counter text: `0.58rem`, `letterSpacing: '0.1em'`, color `#7a7a74`
- Album form field label "MODE JOUR/NUIT": `0.58rem`, `letterSpacing: '0.14em'`, `color: '#7a7a74'` (canonical sub-label role)
- Radio option labels (JOUR / NUIT / NON TAGGÉ): `0.62rem`, `letterSpacing: '0.1em'` (button/counter role — subsumes prior `0.70rem` radioLabel value)
- Inheritance badge suffix (¹ superscript, ! marker): `0.58rem` inline after icon (sub-label/badge role)
- Album row day/night indicator icon: `<Sun size={9} />` / `<Moon size={9} />` — icon prop only
- Reset-override label (`ALBUM ↺`): `0.58rem`, color `#e07070`

## Per-Component Interaction Contracts

### 1. DayNightToggleBadge (inline per-photo toggle — portfolio grid)

**Location:** Overlaid at top-right corner of each photo card. Stacked above the existing ConfirmButton (delete) at `top: '3px', right: '26px'` to avoid collision with delete `✕` at `top: '3px', right: '3px'`.

**Visual states:**

| State | is_day value | Badge render | Background | Icon | Color |
|-------|-------------|--------------|------------|------|-------|
| Untagged | `null` | No badge visible | — | — | — |
| Day | `true` | Small rounded pill | `rgba(200,169,126,0.15)` | `<Sun size={10} />` | `#c8a97e` |
| Night | `false` | Small rounded pill | `rgba(120,140,180,0.15)` | `<Moon size={10} />` | `#8090b0` |

**Badge pill style (inline CSSProperties):**
```
background: (see table above)
border: '1px solid ' + (day: 'rgba(200,169,126,0.35)' | night: 'rgba(120,140,180,0.35)')
borderRadius: '2px'
padding: '2px 4px'
display: 'flex'
alignItems: 'center'
cursor: 'pointer'
width: '18px'
height: '18px'
justifyContent: 'center'
```

**NULL state:** render nothing (no pill, no icon). The clickable area is provided by a transparent 18×18px button always present at the top-right.

**Cycle on click:** `null → true → false → null` (each click fires Server Action immediately; optimistic update applied locally while pending).

**Pending state:** pill opacity 0.5, pointer-events none. No spinner — matches project pattern.

**Accessibility:** `aria-label` = `"Marquer comme jour"` (when null), `"Marquer comme nuit"` (when true), `"Retirer le marquage"` (when false).

## State Machine: 3-State Inline Toggle (Portfolio Photos)

```
           click              click              click
  NULL ──────────► true ──────────► false ──────────► NULL
(no badge)      (amber ☀)       (indigo ☾)      (no badge)

On each transition:
  1. Optimistic: update local React state immediately
  2. Server Action: updatePortfolioPhotoDay(id, nextValue) fires
  3. Pending: badge opacity 0.5, pointer-events: none
  4. On resolve: restore opacity 1, pointer-events: auto
  5. On error: revert to previous state, show error hint
```

## Interaction Flow: Album Photo Inheritance Override

```
Album edit page loads
  │
  ▼
DraggablePhotoGrid receives photos + albumIsDay prop
  │
  ▼
Per photo card:
  is_day === null AND albumIsDay !== null?
    → Render inherited badge (muted icon + ¹)
  is_day !== null?
    → Render explicit override badge (bright icon + !)
  is_day === null AND albumIsDay === null?
    → No badge

  │
  ├─► User clicks INHERITED badge
  │     → Opens override: sets explicit is_day to opposite of album
  │       (if album=day, explicit=night; if album=night, explicit=day)
  │     → Server Action: updateAlbumPhotoDay(photoId, nextValue)
  │     → Badge transitions to explicit override style
  │
  └─► User clicks EXPLICIT OVERRIDE badge
        → Badge shows "ALBUM ↺" in #e07070 for 1500ms
        → Server Action: updateAlbumPhotoDay(photoId, null)
        → Badge transitions back to inherited style (or no badge)
```
