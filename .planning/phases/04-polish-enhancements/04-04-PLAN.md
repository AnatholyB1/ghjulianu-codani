    Component signature:
    ```
    interface VideoTransitionOverlayProps {
      src: string;
      onComplete: () => void;
    }
    export default function VideoTransitionOverlay({ src, onComplete }: VideoTransitionOverlayProps)
    ```

    State machine (implemented as a `fading` boolean state):
    - Mount: `fading = false` (opacity 1 via the CSS transition on mount is handled by a `useEffect` that sets initial opacity via a mounted state — see below)
    - `onEnded` handler: sets `fading = true` (opacity → 0, 300ms CSS transition), then `setTimeout(300)` calls `onComplete()`
    - The overlay mounts with `opacity: 0` initially, then a `useEffect` on mount sets a `visible` state to `true` to trigger the fade-in to `opacity: 1`

    Implementation approach (two-state: `visible` for fade-in, `fading` for fade-out):
    1. `const [visible, setVisible] = useState(false)` — starts false so opacity is 0 on mount
    2. `const [fading, setFading] = useState(false)` — true when video ends, drives fade-out
    3. `useEffect(() => { const t = requestAnimationFrame(() => setVisible(true)); return () => cancelAnimationFrame(t); }, [])` — triggers fade-in on next frame after mount
    4. Opacity computed: `fading ? 0 : visible ? 1 : 0`
    5. `handleEnded`: `setFading(true)`, then `setTimeout(() => onComplete(), 300)`
    6. `handleError`: call `onComplete()` immediately (skip overlay if video fails to play)

    Outer div inline style (per UI-SPEC):
    - `position: 'fixed', top: 0, left: 0, right: 0, bottom: 0`
    - `zIndex: 8000`
    - `background: '#000'`
    - `transition: 'opacity 0.3s ease'`
    - `pointerEvents: 'none'` — never captures clicks
    - `opacity`: computed value above

    Video element:
    - `src` prop passed through
    - `autoPlay muted playsInline`
    - `onEnded={handleEnded}`
    - `onError={handleError}`
    - Inline style: `position: 'absolute', top: 0, left: 0, width: '100%', height: '100%', objectFit: 'cover'`

    Render into `document.body` via `createPortal` from `react-dom` — this avoids z-index stacking context issues from wherever DayNightToggle is rendered in the tree. Guard: `if (typeof document === 'undefined') return null`.

    Name the inline style constants at the bottom of the file following the project convention:
    `const videoOverlay: React.CSSProperties = { ... }` and `const videoFill: React.CSSProperties = { ... }`
