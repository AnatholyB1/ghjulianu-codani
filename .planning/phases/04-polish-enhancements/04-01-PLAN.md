       a. Inline script (D-01) via `dangerouslySetInnerHTML` — reads Zustand persisted state and adds `.day` class synchronously before React hydrates. The exact script content (verbatim — do not alter the JSON access path):

          ```
          try {
            var s = localStorage.getItem('day-night-storage');
            if (s) {
              var parsed = JSON.parse(s);
              if (parsed && parsed.state && parsed.state.mode === 'day') {
                document.documentElement.classList.add('day');
              }
            }
          } catch(e) {}
          ```

          Rationale for JSON path: Zustand `persist` middleware stores `{"state":{"mode":"day"},"version":0}`. The path `parsed.state.mode` is the only correct accessor. The `try/catch` handles `SecurityError` in private browsing.

  <action>
    Create src/lib/prefersReducedMotion.ts exporting a single named function:

    ```
    export function prefersReducedMotion(): boolean {
      if (typeof window === 'undefined') return false;
      return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    }
    ```

    This is SSR-safe: returns `false` on the server (no `window`). In VideoTransitionOverlay and WelcomeModal (plans 04-04, 04-05), this is called in event handlers and `useEffect` callbacks where `window` is always available — but the guard is defensive practice consistent with src/lib/storage.ts patterns.
