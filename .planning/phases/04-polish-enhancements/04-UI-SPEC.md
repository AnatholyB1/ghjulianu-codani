## Animation Contracts

### 1. Content Fade — PortfolioGrid, AlbumsDragTrack, recentAlbums section

**Applies to:** outer container `<div>` only. Navbar, page titles, footer, and track WAAPI animations are NOT affected.

| Property | Value |
|----------|-------|
| CSS property | `opacity` |
| Transition | `transition: 'opacity 0.3s ease'` |
| Fade-out value | `opacity: 0` (set on `fading = true`) |
| Fade-in value | `opacity: 1` (set on `fading = false`, after fetch resolves) |
| Total visible duration | 300ms fade-out → fetch → 300ms fade-in |
| Timing function | `ease` |
| Performance hint | `willChange: fading ? 'opacity' : 'auto'` — promotes to compositor thread during animation, resets to `auto` after |

**Inline style object (applied to outer container):**
```typescript
style={{
  transition: 'opacity 0.3s ease',
  opacity: fading ? 0 : 1,
  willChange: fading ? 'opacity' : 'auto',
}}
```

**AlbumsDragTrack constraint:** fade targets the outermost `<div>` (the `height: 'calc(100vh - var(--navbar-h))'` container), NOT `trackRef`. The WAAPI animation on the track element and the rAF parallax loop are unaffected.

**Track reset on mode change:** When `fading` becomes `true` in `AlbumsDragTrack`, also reset the track position to `translate(0%, -50%)` (prevents stale drag offset carrying over to the new mode's album set).

**prefers-reduced-motion behavior:** The global CSS rule in `globals.css` sets `transition-duration: 0.01ms !important` — content swap becomes effectively instant. No JS guard needed; CSS handles it.

### 3. VideoTransitionOverlay — Mount/Play/Unmount

**Applies to:** `src/components/VideoTransitionOverlay.tsx` — new component.

| Property | Value |
|----------|-------|
| Mount trigger | `DayNightToggle` onClick — local `showOverlay` state in `DayNightToggle`, NOT Zustand store subscription |
| Fade-in | `opacity: 0 → 1`, `transition: 'opacity 0.3s ease'` on mount |
| Fade-out | `opacity: 1 → 0`, `transition: 'opacity 0.3s ease'` on `onEnded` |
| Unmount | After 300ms fade-out completes (`setTimeout(300)` after `onEnded`) |
| Video attributes | `autoPlay muted playsInline` |
| Video source day→night | `/public/transitions/day-to-night.mp4` |
| Video source night→day | `/public/transitions/night-to-day.mp4` |
| Video selection | Determined by mode at the moment of toggle click (before mode updates): current mode `'day'` → play `day-to-night.mp4`; current mode `'night'` → play `night-to-day.mp4` |
| Mode update timing | Mode updates simultaneously with overlay mount (Option A — overlay masks content while it updates) |
| z-index | `8000` |
| Position | `position: 'fixed', top: 0, left: 0, right: 0, bottom: 0` |
| Background | `#000000` (prevents flash of page content through transparent overlay during fade) |
| Portal | Renders into `document.body` via `createPortal` to avoid z-index stacking context issues |

**prefers-reduced-motion behavior:** JS guard in `DayNightToggle.onClick()`:
```typescript
if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
  toggleMode(); // instant mode switch, no overlay
  return;
}
setShowOverlay(true);
toggleMode();
```
Overlay does NOT mount at all when reduced motion is preferred.

**Cross-tab guard:** Overlay triggered ONLY from `DayNightToggle` button click event. Never triggered by Zustand store subscription or `BroadcastChannel` message. Prevents double-firing when another tab triggers a mode change.

### Focus Trap — WelcomeModal

Pattern: identical to `CartDrawer.tsx` `useCallback` + `useEffect` approach.

```typescript
useEffect(() => {
  if (!show) return;
  const focusable = modalRef.current?.querySelectorAll(
    'button, [href], input, [tabindex]:not([tabindex="-1"])'
  ) as NodeListOf<HTMLElement>;
  const first = focusable?.[0];
  const last = focusable?.[focusable.length - 1];

  const trap = (e: KeyboardEvent) => {
    if (e.key === 'Escape') { dismiss(); return; }
    if (e.key !== 'Tab') return;
    if (e.shiftKey) {
      if (document.activeElement === first) { e.preventDefault(); last?.focus(); }
    } else {
      if (document.activeElement === last) { e.preventDefault(); first?.focus(); }
    }
  };

  const previousFocus = document.activeElement as HTMLElement;
  window.addEventListener('keydown', trap);
  first?.focus();

  return () => {
    window.removeEventListener('keydown', trap);
    previousFocus?.focus(); // restore focus on unmount
  };
}, [show]);
```

**Escape behavior:** Dismiss modal WITHOUT changing mode (current mode, defaulting to night, is preserved). Write `'ghjulianu-welcomed'` key regardless (prevents modal from re-appearing).

**Shared JS utility (define once, import where needed):**
```typescript
// src/lib/prefersReducedMotion.ts
export function prefersReducedMotion(): boolean {
  if (typeof window === 'undefined') return false;
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}
```

## Performance Validation Contract

**PER-01 — EXPLAIN ANALYZE queries (run via Supabase MCP `execute_sql`):**

All four queries must show "Index Scan" or "Bitmap Index Scan" (not "Seq Scan"). Execution time must be < 100ms.

```sql
-- 1. portfolio_photos day mode
EXPLAIN ANALYZE
SELECT * FROM portfolio_photos
WHERE is_day IS NULL OR is_day = true;

-- 2. portfolio_photos night mode
EXPLAIN ANALYZE
SELECT * FROM portfolio_photos
WHERE is_day IS NULL OR is_day = false;

-- 3. albums day mode
EXPLAIN ANALYZE
SELECT albums.*, row_to_json(categories.*) as category
FROM albums
LEFT JOIN categories ON albums.category_id = categories.id
WHERE (albums.is_day IS NULL OR albums.is_day = true)
ORDER BY albums.sort_order DESC;

-- 4. albums night mode
EXPLAIN ANALYZE
SELECT albums.*, row_to_json(categories.*) as category
FROM albums
LEFT JOIN categories ON albums.category_id = categories.id
WHERE (albums.is_day IS NULL OR albums.is_day = false)
ORDER BY albums.sort_order DESC;
```
