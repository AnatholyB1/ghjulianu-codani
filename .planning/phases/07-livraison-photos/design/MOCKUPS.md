# Phase 7 mockups index

Static HTML/CSS, no JS framework. Open `gallery.html` (FR/EN and night/day switches, mobile and desktop frames), or a screen directly: `screens/<state>.<fr|en>.html` (append `?theme=day`). Shared `tokens.css` (real site tokens) and `base.css`. All files are regenerated by `node build.mjs` from one template. Fonts load from Google Fonts (offline: falls back to Georgia/system-ui, layout still holds).

| State | File stem | Shows |
|---|---|---|
| Valid, 14 photos | `valid` | thumbnails (placeholders labelled "NN, ratio"), Tout télécharger (ZIP), per-photo download, uses left, expiry |
| Valid, 96 photos | `parts` | 3 ZIP parts list, first 12 thumbnails, "Afficher les 84 autres" |
| Download started | `started` | busy part, indeterminate bar, status text, uses 2 sur 3 |
| Last use | `last` | warning callout, 1 sur 3 |
| Download refused | `dlerror` | 429 alert, nothing consumed |
| Expired | `expired` | terminal, CTA back to the site |
| Used up | `exhausted` | terminal |
| Invalid / revoked | `invalid` | terminal, identical for both |
| Page error | `error` | 5xx, retry |

Render and measure (PNGs go to `shots/`, git-ignored via `.git/info/exclude`):

```
npm i playwright@1.65.0 --prefix <dir>      # once, outside the repo
PW_DIR=<dir> node shoot.mjs                 # 72 renders: 390x844 DPR2 and 1440x900 DPR1, night and day, reduced motion on
```

Measured (last run): 72 renders, 0 issues on overflow, text below 14px, targets below 43.5px, contrast below 4.5 (3 for large), controls overlapping text. Sample data (album, sizes, dates) is invented; photos are never faked.
