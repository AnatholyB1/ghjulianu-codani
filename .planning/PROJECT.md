# Photo Portfolio Application

## Current Milestone: v1.0 Day/Night Photo Filtering

**Goal:** Implement a system to categorize and display photos as day or night with a global toggle switch, light/dark theme switching, and admin controls for marking photos and albums.

**Target features:**
- Day/night photo categorization
- Global toggle switch visible throughout the site
- Call-to-action with explanations
- Light theme activation when showing day photos
- Portfolio filtering to show only day/night photos based on toggle
- Album filtering to show only day/night albums based on toggle
- Smooth animations when switching between day/night views
- Admin interface to mark photos as day/night
- Admin interface to mark albums as day/night using checkbox/slider
